# 红果短剧 3.9

**状态：已正式发布。** 3.9（内部 `3.9.0`）已于 2026-10-27 14:15（Asia/Shanghai）正式发布，标签 `v3.9`。冻结源码 `4a88f2ea597101a5c2e92f2ab564afee9c5167e0`；三端 16 项附件的远端 SHA256 与大小逐项匹配。双 Mac App 与 DMG 已完成 Developer ID 签名、Apple 公证 Accepted 和装订。Windows CI 40458538824 的便携播放、安装、重装与真实 1.80 升级资料保留通过；EXE 未签名。

## 恢复播放与下载

- 首次 App 取流注册匿名播放设备，同一进程的播放、下载与预取共用身份，解决本轮实测的 `HTTP 200 + 空正文`。不读取账号、Cookie 或设备令牌，不将身份写入文件。
- 兼容当前直接播放模型与旧备用模型；继续限制 HTTPS/CDN、分集匹配、密钥和清晰度。
- 下载完成前增加前三秒真实解码检查；网页文件损坏时继续尝试 App 来源。不会反复下载同一个已损坏的 App 片源。
- 三部剧各两集 1080P 取流成功；一集完成真实下载、解密、Range 读取和全片解码。细节见 [播放恢复记录](release-3.9-signature-recovery.md)。

## 搜索当天新剧

- 官网没有标题匹配、搜索接口异常，或短剧名被更长老剧名遮蔽时，继续从 App 近 7 天上新目录补搜。
- 真人剧与 AI 剧上新目录默认各翻两页，最多使用 200 条候选；补搜结果上限从 10 条提高到 20 条，繁忙日当天新剧落在首屏之外的概率更低。
- 官网已有精确标题时不额外请求 App；补搜失败不覆盖官网结果，加载更多仍固定官网通道。
- 单字、纯标点或不足 900 毫秒的剩余预算不触发补搜；有官网结果时补搜最多 2.5 秒，其他补搜最多 8 秒；部分失败会明确提示并短暂退避。

## 缓存后续两集

- 修复预取失败后 `prefetchRef` 不释放、没有重试，导致切到该集时才开始下载的问题。
- 预取失败立即释放本次请求并记录 15 秒退避；退避结束后随 `timeupdate` 重试，不再让一次失败锁死整部剧。
- 当前集起播后最多准备后续两集可在线播放的分集；锁定、已下载、本地可播和不存在的分集跳过。
- 由第一集切到第二集时，第二集直接复用准备结果，第三集的准备继续保留；到新位置后再补齐新的第二集窗口。
- 跳到更远集数时，目标集之前或不同清晰度的旧预取立即释放；关闭缓存、切剧、换清晰度或卸载播放器时释放全部队列。
- `handlePlaying` 先记录当前媒体已起播与断点，再检查 React 的 `canPlay` / `playbackVersion` 状态；避免 `playing` 早于状态更新时永久跳过预取。

## 画中画小窗

- 播放控制条新增「画中画」按钮，调用系统原生 Picture-in-Picture。
- 小窗复用应用内同一个 `<video>` 元素，可拖动、置顶、暂停与关闭，不创建第二路在线会话，也不重复下载。
- 自动连播、切集或切换清晰度导致 `source` 变化时不再主动关闭画中画；只有播放控件真正卸载时才退出系统小窗。
- 进入/退出事件同步按钮的 `aria-pressed` 和文案；系统不支持、用户手势不足或请求被拒绝时显示可读提示。
- 小窗暂停、播放、结束等媒体事件仍由现有播放器处理，断点续播和连播逻辑保持不变。

## 全屏与小窗模式

- 播放器提供全屏按钮和 `F` 快捷键：横屏进入播放器全屏，竖屏填满当前窗口，`Esc` 退出。
- 顶部既有小窗能力统一命名为「小窗模式」：主窗口缩为 400 × 600 的置顶窗口并继续播放；在 Electron 支持工作区 API 的平台上设为所有虚拟桌面可见。鼠标移开时暂停隐藏，移回继续。
- 小窗模式可通过 Esc、Dock 或窗口菜单恢复；显示/隐藏、原始窗口尺寸、最小尺寸和置顶状态都会还原。
- 系统画中画适合跨应用观看；主窗口小窗模式适合保留完整播放器控件和选集体验。

## 边界

- 平台接口可能再次变化；本次样本成功不保证所有作品或长期可用。#54 创作者合集、#58 会员接入未支持；#55 合并异常尚未确认根因。

- 上新补搜读取 App 近 7 天目录，默认每个分类两页；当天条目若超出候选范围、上游目录缺项或 App 接口不可用，仍可能搜不到。
- 双集预取会提前占用网络并使用应用在线缓存额度；自动连播只会保留与当前剧集、清晰度一致的后续目标，其他请求会被释放。
- 原生画中画的实际窗口位置、置顶和跨虚拟桌面行为由操作系统决定；应用不伪造第二套在线会话，也不额外下载视频。
- 画中画首次进入需要用户点击并满足浏览器用户手势要求；尚未起播或系统不支持时会提示。
- 画中画只显示视频画面，不包含应用内弹幕、画质增强画布或自定义控制条；退出后恢复应用内播放。
- 主窗口小窗模式的 400 × 600 尺寸受屏幕工作区限制；跨虚拟桌面可见性依赖 Electron 平台工作区 API，Windows 虚拟桌面由系统行为决定；鼠标移开隐藏依赖指针位置检测。
- 未覆盖实体 Intel Mac、实体 Windows、干净 Gatekeeper、长期播放、完整应用内跨版本更新及画中画跨虚拟桌面；真实播放成功不等于这些专项通过。
