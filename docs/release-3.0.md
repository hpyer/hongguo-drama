# 红果短剧 3.0

源码／发行目标为 3.0（内部 3.0.0），基于已发布 2.9。此文档不代表构建、签名、公证或发布已完成。

## 修复范围

- 强制直连和关闭代理时，统一处理继承的 `ALL_PROXY` / `all_proxy`，切回系统模式恢复启动环境，避免窗口与主进程请求代理行为不一致。
- 清除下载任务记录后，删除全部已下载仍按剧集档案定位合集；保留活动任务保护，不扩大到无法确认归属的目录。
- 收藏与上新播放优先使用本地已登记档案，只有缺档案才联网解析；上游不可用时不会阻断已有本地视频的播放入口。

保留 2.9 时间轴弹幕、观看记录、播放器和缓存管理改进；第三方来源与 GPL 声明不变。

## 验证与发行

基于 2.9 先复现再修复：代理与合集新增回归在修复前失败；修复后下载安全检查 27 项、收藏播放入口 8 项通过。发行前单元测试及 71 项平台检查通过，前端构建通过。

三端构建、Mac 签名公证装订及最终附件核对结果在完成后补充。Windows EXE 未签名。

真实播放只使用隔离资料与正常视频；自动回归不代替实体 Windows／Intel Mac、干净 Gatekeeper、长期播放和应用内更新重启端到端验收。
