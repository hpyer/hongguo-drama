# 红果短剧 3.6

**状态：正式发布。** 内部版本 `3.6.0`，标签 `v3.6`，于 2026-10-26 发布。三端 16 项附件的远端 SHA256 与大小已核对；双 Mac 应用及 DMG 已签名、Apple 公证 Accepted 并装订，Windows EXE 未签名。冻结源码 [`887862f`](https://github.com/jackotom/hongguo-drama/commit/887862f449b87c56a01b565c849057756266d5a5)；后续文档提交不改变标签和已发布包。

## 分集拉取提速

- 官网分集页优先使用项目已有的可信 DNS 请求，避开会挂起的 CDN 边缘；普通 DNS 仍作为兜底。
- 第一次竞速最多等待 1.5 秒；0.6 秒仍未返回时并行再开一组，成功者先展示，避免干等坏节点。
- 重试同时尝试可信 DNS 与普通 DNS 的 player／detail 两条路径；备用接口的 HTTP 200 空响应按网关丢包重试，最多 3 次。
- 错误提示统一为“加载超时或连接中断”，不再直接显示 `aborted`。
- 真实 10 部剧集样本最终全部成功，0.49–1.21 秒，平均 0.81 秒；最终预览 UI 实测 0.75–1.12 秒。

## 发现与热播双目录

- 发现短剧默认使用「App（快速 · 部分片单）」官方元数据目录，保留「官网（完整目录）」手动选择并记忆。热播推荐的红果榜单也提供独立线路选择，单独记忆。
- 两条线路的片单、缓存和分页会话分开；换线取消旧列表等待与播放回调，晚到响应不串入新线路。失败时仍可手动切线，不自动混用榜单。
- App 第一页可保留为冷启动预览；第二页起依赖实时游标，不写入本机持久缓存。
- App 分类展示接口返回的题材，综合、真人、漫剧和 AI 剧分别选择对应热播榜；未提供总数、总页数或完结状态时不虚构。

## 分页与失败恢复

- 发现与推荐使用不同的 App 目录会话；推荐刷新不再清掉发现页的后续游标。
- 页码跟随已成功加载的片单。下一页失败、取消或超时后仍标示旧页，再次点击重试同一目标；会话真正失效时停用旧分页并提示刷新回首页。
- 切题材或请求 App 首页时，旧片单可继续显示，但旧分页不能套到新查询。官网数字分页同步遵守题材边界。
- 官网及其他内置来源成功列表可保留本机持久缓存（最多 8 页，7 天过期）；自定义源仅使用随配置失效的内存缓存。

## 官网、搜索与显示

- 官网目录在直连模式下同时尝试 Electron 网络层与官网固定域名的可信 DNS 路径；启用系统代理或自定义代理时只走代理，不擅自回退直连。
- 多来源搜索渐进展示；慢来源不再遮住已返回结果。点击已返回结果时结束旧搜索加载状态。
- 热播推荐读取 App 剧情简介。
- 西饭仅对已核实的特定上游标题冲突隐藏错误副标题，沿用“第 N 集”显示；不改原任务标题、文件名、保存路径或播放映射。
- 已知 HEIC 封面改用同一官方图片对象的 JPEG 变体，未知格式保留占位。

## 验证与边界

- 本地全量 `npm test` 通过：单元测试及 86 项平台检查。分集回归 `check-source-recovery` 15/15、`check-native-performance` 8/8，身份检查通过。
- App 与官网仍可能间歇超时；分集并行重试覆盖大部分坏边缘，但不保证每次必然秒开。
- 双 Mac App 与 DMG 均取得 Developer ID 签名、Apple 公证 Accepted 和票据装订；两种 DMG 均完成只读挂载与签名、版本、架构核对。Windows 7 项资产来自 [CI 40280746595](https://github.com/jackotom/hongguo-drama/actions/runs/40280746595)，便携播放、新装、重装和真实 1.80 → 3.6 升级资料保留通过；EXE 的 Authenticode 状态为 **NotSigned**。源码 CI [40280104020](https://github.com/jackotom/hongguo-drama/actions/runs/40280104020) 与发行资产绑定同一冻结提交。
- 最终签名 arm64 包实际下载两集 HEVC/AAC 视频，前 10 秒解码无错误，本地第 1 集播放至 15.7 秒有画面；x64 Rosetta 包隔离启动并正常退出。
- 未覆盖实体 Intel／Windows、启用 Gatekeeper 的干净系统、长期播放、完整应用内跨版本更新和人工听音；西饭上游影片身份未确认。
