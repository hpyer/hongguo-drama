# 红果短剧 2.6

## 全屏播放

- 顶部显示剧名和当前集，随播放控件显示与隐藏，便于确认正在看的内容。
- 底部提供悬浮选集网格，直接选择分集并突出当前集。
- 播放器底部新增清晰度菜单，沿用已有取源与切换流程；原管理区选择器保持同步。
- 选集面板固定标题、滚动集数，打开时定位当前集；未开放分集不可选择。
- 弹幕只避让底部控制栏，避免全画面悬浮层将多轨弹幕挤成单行。

## 清晰度限制

红果来源提供自动、720P、1080P 三种选择，指定画质使用既有 App/API 取源，不可用会提示，不会自动降级。网页源画质上限取决于上游，自动模式可能取得低清画面。其他来源显示“由片源决定”。

菜单显示视频实际分辨率；自动模式下，底部入口也显示当前画面分辨率。该数值不代表来源的最高画质。切换画质保留播放进度及暂停状态，切集沿用所选画质；原有本地文件保留。

## 版本与验证边界

本轮发行版本为 2.6，标签为 v2.6，包配置使用 2.6.0。三端共用同一源码；安装包、对应源码和校验文件以 GitHub 发行页为准。

本文件记录变更范围；本版构建、签名、公证和验收结果见 GitHub 发行说明。历史版本的检查不代替本轮验收。Windows EXE 未签名，实体 Windows、Intel Mac、启用 Gatekeeper 的干净环境与长期播放须单独记录覆盖情况。

本版指定正常视频验收素材缺失，未进行实际视频和声音播放；控件及切换流程的离线验证不替代实播验收。各平台构建与安装验证结果见发行页。
