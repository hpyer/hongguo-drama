# 红果短剧 2.5

## 播放与剧库

- 还原加密媒体封装时，按原始编码和配置识别 H.264／HEVC，避免一律标记成 HEVC；编码信息缺失或矛盾时明确报错。
- 分集信息加载失败显示原因与重试入口，避免停在没有恢复入口的空白状态。
- 兼容模式、看完自动删除仅在设置成功保存后切换；保存与自动删除失败时明确提示。
- 修正纯数字中文季数解析，并避免将括号中的年份误识别为季数。

## 下载与更新

- 同一部剧再次合并时自动使用带序号的新文件名，保留原合集；启动时清理已记录合并任务的遗留临时工作文件。
- 正常退出时暂停下载、取消子进程并等待临时文件收尾；超过 10 秒则取消退出并提示，避免强制结束任务。Windows 关主窗口也走正常退出流程。
- 其它任务正在下载时，仍可将暂停、失败和等待任务重新加入队列。
- 已完整下载的更新在安装失败后保留再次安装入口，无需重新下载；取消更新后清除安装就绪状态。

## 搜索与权限

- 可见搜索窗口和后台查新、搜索嗅探分开，后台导航或超时不会打断、销毁用户窗口。
- 远程页面权限请求与权限检查默认拒绝；仅可信主窗口保留全屏与剪贴板功能。
