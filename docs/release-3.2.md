# 红果短剧 3.2（源码／发行目标）

内部版本 3.2.0，基于 3.1 正式版，计划标签 v3.2。本文记录源码改动及已完成的验证；构建、签名、公证、安装与正式发布尚待本轮发行流程确认，不沿用上一版结果。

## 片单缓存与刷新恢复

- 热播推荐按来源配置、来源及分类保存会话片单。切换分类或离页返回时先显示缓存，再更新内容；随机推荐保持独立行为。
- 原生目录缓存有效期调整为 120 秒，主动刷新仍绕过缓存。缓存不保证上游实时更新或首次请求成功。
- 刷新超时、失败或返回空列表时保留已有片单，并显示失败或取消提示；空响应不覆盖已缓存内容。
- 更新完成后保留仍在片单中的选中剧集；等待更新期间切换到下一部，不被迟到响应拉回第一部。
- 来源配置变更、切换来源／分类及取消更新会使旧请求失效，避免旧列表或旧解析结果覆盖当前选择、触发过期播放。
- 发现页已有内容时使用紧凑错误提示，保留总数、题材、分页与海报；首次加载没有片单时仍提供完整错误和重试入口。

## 已完成验证

- 片单缓存及相关状态定向检查 8 项通过；发现页紧凑错误提示新增断言先失败、修复后通过，相关 Browse 检查共 4 项通过。未把未重跑的历史测试计为本轮通过。
- 前端构建通过，保留既有 Vite CJS API 与产物大小提示。
- 3.2 版本检查通过：225 组历史版本比较、3.1 升级至 3.2／同版本不重复更新、包与锁文件版本一致、对外产物两段命名。受控根目录 21 项均已准备本轮变更；最近提交说明需提交后再核对。
- 在隔离 Electron 预览中使用实际编译界面及目录处理器：真实发现目录返回 24 张海报、总数 800；综合及漫剧榜各返回 20 条，真人榜在首次超时后再次加载成功。
- 在目录响应边界注入空列表、超时及延迟，确认刷新失败保留旧海报／片单、重试恢复、更新中切换剧集后保留选中项、取消后晚到结果不覆盖、离页返回先显示缓存。
- 实际窗口确认紧凑错误提示下首排海报仍可见；真实来源随后超时也保留已有内容。

## 验证边界与发行待办

- 本轮界面检查不等于真实弱网整形；故障注入位于目录响应边界。上游冷请求仍可能在约 10 秒后超时，不承诺消除来源延迟或服务故障。
- 尚未进行本轮真实播放／下载验收、最终三端安装包验收、签名、公证或发布。界面及源码检查不能代替这些步骤。
- 正式发布前，从同一冻结提交构建三端产物。双 Mac 应用和 DMG 分别完成 Developer ID 签名、Apple 公证与装订；最终更新 ZIP 从最终 App 重新生成。
- Windows 安装版及便携版需完成对应 CI 验证；当前没有代码签名证书，EXE 不宣称已签名。实体 Intel／Windows、干净 Mac Gatekeeper、长时稳定性与应用内更新完整链路需如实标明覆盖范围。
- 汇总准确对应源码、媒体工具对应源码、更新清单与 SHA256 校验文件后统一发布。版本与根目录最近提交说明规则见 [RELEASING.md](RELEASING.md)。
