# 红果短剧 2.4

## 播放失败修复

- 官网播放页的 `VideoObject.url` 改为只包含剧集 ID 后，继续校验页面、分集及官方媒体路径中的视频 ID，再接受对应片源。不会把推荐视频绑定为当前分集。
- App 与旧接口媒体请求默认不附 `novelquickapp.com` 的网页 Referer。已有 Referer 的 App/API 请求遇到 403 时去掉后重试一次；缺失 Referer 的兼容回退仍保留。取消、Range 和重试上限保持有效。
- 官网页面公开画质可能仅为 360p；“自动”仍优先兼容片源，指定 720p/1080p 通过 App 片源获取，无对应画质时明确失败，不冒充高清。

## 连播与升级

- 在线播放准备成功、预取下一集完成时只刷新在线缓存统计，不再每次同步扫描全部下载目录。管理和清理操作仍保留必要的存储统计。
- Windows 便携升级提示说明退出旧程序、使用 setup 安装包和新快捷方式。继续使用便携版时需完整解压并启动新文件；无需清空整个系统 Temp 或观看资料。

## 验证与边界

官网路径与媒体请求头定向回归、四集连续播放的存储统计回归已通过。后者将原有 8 次下载目录扫描减少为 1 次初始化扫描，并保留 8 次在线缓存刷新。

Apple Silicon/macOS 26.6.2 上下载了真实短剧前 3 集 1080p 文件，全程静音：前两集自然播放完成并自动切集，第 3 集播放约 88 秒后结束测试。已观察全屏进入与退出；全屏窗口隐藏时暂停，恢复可见后继续。此记录不是三集完整连播或 macOS 27 的验收结论。

此次优化移除了确定的同步扫描成本，不能据此保证所有 Mac 间歇掉帧都已解决。实体 M1 Pro/macOS 27、Intel Mac 与 Windows GPU 解码仍需对应设备反馈；最终实播、签名、公证、安装验收状态以发行页为准。

三端对外版本统一为 2.4，内部 SemVer 为 2.4.0。Windows EXE 未签名；不要求关闭系统安全保护。更新保留原资料与下载视频。
