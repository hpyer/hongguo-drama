# 红果短剧 2.4

## 播放与剧库

- 离开剧库会暂停播放，并撤销等待下载和异步取源的自动开播意图；返回仍保留断点，可主动继续播放。
- 重新进入剧库时刷新剧集列表，搜索下载的新剧可见；刷新列表不重置当前进度。
- 下载完成和文件清理后更新空间统计的失效状态，打开管理面板时按需刷新。
- 减少下载管理和等待播放时重复扫描磁盘的开销；下载回退停止、失败或入队失败后停止无效轮询。

## 缓存、安全与退出

- 分享链接和每次跳转复用公网地址及连接时 DNS 校验，拒绝本机、内网和不安全解析目标。用户明确配置的代理仍是独立信任边界。
- 转码入口统一校验正整数集数，防止异常参数越过兼容缓存目录。
- 缓存淘汰保护临时文件、活动任务和当前输出，修复较大输出刚转完即被清理的问题；启动时清理异常退出遗留的临时片段。
- 退出时取消并等待视频准备和合并任务收尾；超过 10 秒会提示并取消本次退出，保留原始分集，避免无限等待或强退。Mac 关闭窗口与真正退出分别处理。
- 本地保存恢复成功后清除写入错误提示和更新阻塞；原始资料读取损坏时仍保持保护。
- 删除等待重试的下载时清除对应重试计时器，避免任务已删但安装更新仍受阻。
- 红果 Referer 兼容回退限定于 App/API 来源，不再影响其他来源。
- 将 `follow-redirects` 从 1.16.0 升至 1.16.1，修复重定向凭据保护相关安全公告。

## 播放取源与连播

适配官网播放页 canonical 地址变化，继续校验剧集、分集和媒体身份；减少取源、预取后的全库扫描；完善 Windows 便携版升级说明。这些问题多数为既有缺口，不全部属于 2.4 回归。

## 版本与验证边界

公开版本与下载文件名为 2.4，标签 v2.4；包配置和更新清单使用 2.4.0。

最终测试、三端构建和签名公证结果见发行页。Windows EXE 未签名。此次不新增实播，不用安装验收代替播放验收；实体 Windows、Intel Mac、开启 Gatekeeper 的干净环境与长期播放未覆盖。没有覆盖本机正式应用或变更用户观看资料。
