## 本次找到的原因

旧播放请求每次生成随机 `device_id/iid`。目录和搜索可用，但播放 `multi_video_model/v1` 返回 `200 + 0 字节`；单凭空响应本来不能判断具体原因。

匿名注册对照结果：同一首集、同一接口、相同 UA 和正文均不加签名：

| 设备身份 | HTTP | 正文字节 | 结果 |
|---|---|---|---|
| 本地随机身份 | 200 | 0 | 无模型 |
| 平台注册的匿名身份 | 200 | 22,658 | code 0，5 档片源 |

这直接支持本次样本的返空与未注册设备身份有关；不能据此判断所有接口都不再需要签名，也不能承诺所有地区、作品或后续平台版本可用。

注册后的响应直接包含 `video_model.video_list` 数组、HTTPS 播放地址、尺寸和 CENC 加密信息。旧代码强制请求 `fallback_api`，漏掉了当前直接模型，必须一起适配。

## 本地实现

- `playback-device.js`：首次 App 取流时懒注册；同进程的播放、下载和预取共享一次注册的 Promise 和身份。失败也保留失败结果，避免并发或重试不断新建设备；重启后才会重新注册。
- 注册使用随机标识和固定模拟安卓参数，不登录、不发短信、不读取用户账号；只提取 `device_id/install_id/cdid`，不保存 `device_token`、Cookie、完整响应或身份文件。应用重启不复用身份，首次播放会向平台注册新匿名设备。
- 注册请求固定官方 HTTPS 端点，8 秒上限，沿用受限传输；精确保留字符串 ID，拒绝零值、格式错误和已经丢失精度的数字 ID。
- `app-source.js`：注册身份用于原批量接口；播放请求按成功对照使用无签名路径。搜索、目录仍使用原有签名。
- 优先解析直接 `video_list`，有直接模型时不访问旧备用端点；保留仅含旧模型时的回退。仍精确匹配所选分集，不借用响应中其他集的模型。
- 保留 HTTPS/CDN 域名限制、兼容编码筛选和清晰度约束；加密片源缺少有效密钥会失败，不当作明文播放。
- `hongguo.js`：匿名注册失败有单独可读原因，不混成 JSON 解析失败。
- `main.js`：网页文件真实解码失败后可继续查询 App；损坏的 App 文件不会反复下载同一地址。
- 下载测试增加可被 ffprobe 探测、却不能真实解码的损坏 MP4；预取测试检查实际“正在加载视频…”与“正在缓冲在线播放…”两种遮罩。

## 本机验证

所有取流抽查复用同一进程内匿名身份，没有逐集注册或导入他人的设备身份；身份不写入文件。

| 样本 | 分集 | 1080p 取源 |
|---|---|---|
| 三载沉眠，隐龙醒世 | 1、2 | 2/2 成功，1080×1920 HEVC |
| 明月不照长子窗 | 1、2 | 2/2 成功，1080×1920 HEVC |
| 晚风落蝴蝶 | 1、2 | 2/2 成功，1080×1920 HEVC |

首部首集另测自动清晰度，成功选择 1080p。真实媒体验证：下载 8,785,814 字节，内置 FFmpeg 解密和封装成功；ffprobe 确认为 1080×1920 HEVC、AAC 音频、114.733333 秒。起始 3 秒真实解码通过；临时文件已清理。

随后用隔离的临时资料目录运行真实 `main.js` 处理逻辑，复用同一身份：`prepare-online-play` 成功，解密后 8,738,017 字节；自定义播放协议返回 `206` 和所请求的 1,024 字节；下载任务为 `completed`、实际清晰度 `1080p`、仅一次完成事件。该输出的 **114.733333 秒全片真实解码通过**，无标准错误输出。临时文件和缓存均已清理；没有启动真实 Electron 窗口或改动用户资料。

实网使用修复后的真实取源函数和已经授权取得的内存身份；没有为测试再次触发生产注册模块。注册模块用离线协议测试核对请求二进制、字段、并发共享、失败缓存和 ID 精度。

相关检查：下载集成 26/26、预取 8/8、App 取源 13/13、匿名设备模块 6/6、下载清晰度 13/13、来源恢复 15/15，以及直接模型和安全边界检查通过。来源恢复中的旧测试曾期待空正文重试，现改为网络中断重试、空正文立即停止，分别验证。

## 尚未证明的部分

- 真实桌面画面已确认；人工听音、拖动、续播和系统窗口行为不由音视频解码测试替代。全量测试结果见发行说明。
- 实网取流抽查范围为三部剧各两集，不代表所有地区或作品均可用。
- 首集全片解码成功不代表其他分集或合并拼接点正常；#55 合并无法播放的根因仍未确认。
- #54 的创作者视频/合集类型仍未支持；不能把 `video_id` 当作当前真人/AI 短剧的 `series_id`。
- 没有新增会员登录或付费内容支持，不改变作品的访问权限。
- 正式签名、公证和发布状态见发行说明；旧安装包不会因修改源码自动修复。
