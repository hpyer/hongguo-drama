# 红果短剧 4.3

**状态：已正式发布。** 4.3（内部 `4.3.0`）已于 2026-10-28 20:26（Asia/Shanghai）发布，标签 `v4.3`，冻结源码 `81f354d48e1c163eb9b5b419cd5faa855f5fd1da`。三端 16 项附件远端 SHA256 与大小逐项匹配，10 个匿名下载入口通过。

## 新增内容

- 左侧导航在「设置」上方新增独立「登录管理」；原「观看记录」页保持本机记录逻辑不变。
- 使用红果官网二维码登录，手机红果 App 扫码并在手机确认；不接入手机号验证码。
- 登录管理页读取当前账号最近 50 部 APP 观看记录，支持按剧名搜索。
- 在登录管理页点击 APP 记录才会进入播放器；优先按云端分集 ID 续播，无法确认分集时停止并提示，不把云端时间套到第一集。
- 登录态经 Electron 系统安全存储加密，保存在独立文件，不进入普通设置、观看历史或备份。
- 网页登录 Cookie 使用独立内存会话；启动、取消、退出和失效时清理，不写默认持久 Cookie 库。
- 登录恢复优先显示本地加密账号缓存，后台复核会话；观看记录单独加载，不阻塞账号信息。
- HEIC 封面转换为普通 WebP，加载失败保留播放图标；大整数分集 ID 保持字符串精度。
- 本版只读云端观看记录，不批量导入本机观看历史，不上传本机观看历史。

## 协议来源

扫码、网页会话验证与 APP 观看记录字段参考 `tsukiyo-zero/hongguoTV` 的 GPL-3.0-only 实现：
`kotlin-tv/core/src/main/kotlin/com/hongguotv/core/WebLogin.kt` 与 `CloudAccount.kt`。
本项目的 Electron 版本重新实现登录态存储和播放映射，不复制其 Android Keystore 或 UI。
